# Insight Flow Actions

Kun je de actielijst van @project:e302dd00-7f43-4429-95ef-0398b203edcd:"BookFlow Navigator (48)"  namaken met het concept van het kpi dashboard combineren met de stijl/layout/vormgeving van ook @project:10a083d0-1e62-4d23-92e9-c82e74048b4a:"BookFlow Navigator" . Het dashboard moet voor nu alleen werken dat als ik op SLA healthcare klik ik doorverbonden word naar de actielijst met foto en 5w1h die open staan onder die KPI. De vorm die je gebruikt om een nieuwe actie aan te maken mag je totaal van @project:5ae588bc-49bb-4c82-9c15-fb5e18cf8f28:"Simple Root Coach" meenemen met voorbeelden erbij. Naam en tekst van het product is niet belangrijk er hoeft geen uitleg of dergelijk bij, die tekst is compleet overbodig. Het is hetzelfde concept als de referentie projecten maar een nieuw dashboard vorm ervan om het overzichtelijk te houden. Vandaar zo simpel mogelijk.
